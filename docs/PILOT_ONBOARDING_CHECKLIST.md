# Pilot Onboarding Checklist — Lauris Learn
## STEP-BY-STEP GUIDE TO SET UP A SCHOOL FOR LAUNCH

**Last Updated:** May 2026  
**Audience:** School administrator, onboarding specialist  

## PHASE 0: PRE-ONBOARDING

- [ ] Signed Terms of Service received
- [ ] Privacy Policy reviewed by school
- [ ] Admin email confirmed
- [ ] Admin account created and setup complete
- [ ] MFA enabled (recommended)

## PHASE 1: SCHOOL CONFIGURATION

- [ ] School name entered
- [ ] School address entered
- [ ] Contact email entered
- [ ] School year created and marked active
- [ ] Academic periods added (Regular Term minimum)
- [ ] All holidays added to calendar

## PHASE 2: CLASS STRUCTURE

- [ ] Class levels defined (PreK, K, Grade 1, etc.)
- [ ] At least 1 class created
- [ ] Class assigned to academic period
- [ ] Class capacity set

## PHASE 3: FINANCE SETUP

- [ ] Fee types created (Tuition minimum)
- [ ] Tuition configuration added (optional)
- [ ] Discounts setup (optional)

## PHASE 4: STAFF MANAGEMENT

- [ ] All teachers added with email
- [ ] All teachers invited via email
- [ ] All teachers can login and access their classes

## PHASE 5: STUDENT MANAGEMENT

- [ ] All students added
- [ ] All allergies and medical info entered
- [ ] All guardians added with email
- [ ] All students enrolled in classes

## PHASE 6: PARENT INVITATIONS

- [ ] All parents/guardians invited
- [ ] Test parent account can login
- [ ] Parent can see child's information

## PHASE 7: DOCUMENTS

- [ ] Document coordination enabled
- [ ] Test document uploaded and accessible

## PHASE 8: ATTENDANCE

- [ ] Sample attendance marked
- [ ] Attendance visible on parent portal

## PHASE 9: BILLING (OPTIONAL)

- [ ] Billing records created (if applicable)
- [ ] Sample payment recorded
- [ ] Billing visible on parent portal

## PHASE 10: EVENTS & COMMUNICATION

- [ ] Sample event created
- [ ] Sample announcement sent
- [ ] Visible on parent portal

## PRE-LAUNCH FINAL CHECKS

- [ ] All students enrolled in classes
- [ ] All parents invited and invites sent
- [ ] All teachers invited and invites sent
- [ ] No test data remaining
- [ ] Teacher access verified
- [ ] Parent access verified
- [ ] Attendance working
- [ ] Communication working
- [ ] Documents working

## GO-LIVE

- [ ] Send go-live email to all families
- [ ] Monitor first 24 hours
- [ ] Respond to support requests
- [ ] Verify no data corruption

**End of Pilot Onboarding Checklist**
